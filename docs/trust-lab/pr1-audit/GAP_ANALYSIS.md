## Summary of the main gaps
1. **No registration path** that records owner, `operator_type` and `code_fingerprint` (the `qants-` reservation at public key issuance was fixed on 17 Nov 2026).
2. **PAL is not published or wired to anything.** It is the strongest piece (permission snapshot, replay, four separate indicators) but lives only in `/workspace/mizan-ledger-pal`.
3. **No proof engine.** Ledgers are local-clock only. OTS exists as a one-off file stamp (still pending in the local copy), and nothing tracks the five proof states.
4. **No sandbox and no `qants` CLI.** Existing CLIs are `mizan-ledger verify/summary/pal`.
5. **Three hash-chain dialects** (mizan-ledger/1, mizan-pal/0.1, options lab v1) with different canonical-JSON settings. The verifier must accept all three without rewriting any.

## What is NOT a gap (do not rebuild)
Metrics, commitment scheme, hash chains, PAL policy engine, offline verifiers, seed ledgers, production passports. The founder's rule "extend, do not replace" is satisfiable: every missing tool can be built on these.
